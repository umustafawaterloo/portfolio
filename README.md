# Umar Mustafa Portfolio

**Live site:** https://umarmustafa.vercel.app/

## Tech stack

- [React](https://react.dev/) + [Vite](https://vite.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/) for styling
- [react-icons](https://react-icons.github.io/react-icons/) for technical-skill and contact logos
- [embla-carousel-react](https://www.embla-carousel.com/get-started/react/) for the project carousel

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check + production build
npm run preview  # preview the production build locally
npm run lint      # oxlint
```

## Content

All page content (about text, internships, projects, skills, contact links)
lives in typed data files under `src/data/`, so updating the site's content
doesn't require touching any component code.
